# Test Assets & Validation Renders

This directory contains test inputs, photographic fixtures, calibration test patterns, and rendered output images used for visual and sensitometric validation of the `fgrain` simulation engine.

## Directory Contents

### 1. Test Inputs & Photographic Fixtures
- `DSCF*.JPG`: Real photographic exposures used for full-resolution and crop-level grain testing.
- `clean_test.webp`, `test.jpg`, `test.png`: Baseline test images covering a range of exposures and edge dynamics.
- `crop_test_input.png`, `swing_input.png`, `subcrop_input.png`: Cropped regions used by benchmarking and diagnostic examples in `examples/`.
- `sample_scene.png`: Synthetic geometric target generated by `examples/make_sample.rs`.
- `sweep_in.png`: Exposure calibration gradient input.

### 2. Validation & Calibration Renders
- `clean_test_*.png`: Multi-resolution and supersampling evaluation renders (e.g. autoscale, supersampled, Klotz profile comparisons).
- `detail_*.png`: High-magnification crops examining crystal grain morphology and edge acutance.
- `fft_spectrum.png`: Power spectral density analysis confirming Wiener noise characteristics.
- `film_grain_gradient.png`, `film_grain_halation.png`, `film_grain_t-max.png`: Reference outputs from the CLI demonstration routines.
- `test_cpu_output.png`, `test_gpu_output.png`: Parity verification renders between CPU Rayon and GPU compute shader pipelines.
- `sweep_out*.png`, `step_test*.png`, `ramp_test*.png`: Hurter-Driffield sensitometric response curve test outputs.
